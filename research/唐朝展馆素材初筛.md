## 4. 首版规模建议：六个展区、24个核心展项

这是内容范围提案，尚未全部定稿或备齐素材。“展项”包含地图、事件、人物、书画及文物，不等于24件都已拥有三维模型。

| 展区 | 四个核心展项候选 | 开放探索方向 |
|---|---|---|
| 时代入口 | 长安空间图；唐朝建立；武周与洛阳；安史之乱 | 时间跳转、城市关系、人物选择、前后比较 |
| 出行与交流 | 骑马俑组合；骆驼俑；载乐骆驼俑；兽首玛瑙杯 | 行旅、交通、商旅、文化交流、器物传播 |
| 衣饰与容仪 | 女立俑；铜镜；两套明确标为现代示意的唐风服饰 | 发式、衣物细节、纹饰、生活视角、真实证据与现代想象的比较 |
| 器用与生活 | 卧牛；开元通宝；白釉执壶；一组待定茶具 | 材质、制作、用途、生活条件、交易；价格须有依据或明确为模拟 |
| 信仰与艺术 | 造像碑；莫高窟跪姿菩萨；天龙山坐佛；镇墓兽 | 姿态、造型、材质、题记、用途、流传经过 |
| 诗书与时代 | 《照夜白图》；《兰亭序》神龙本；李白；杜甫 | 观察书画、关联诗歌与时代、区分原作/摹本、比较人物经历 |

展区是导航入口，玩家可以跨区跳转；互动不按上述顺序强制进行。每个文物记录自身时间范围，不能因同属唐朝展馆就默认同时出现。李白、杜甫需要选定原典与可靠注释后再进入具体内容制作。

## 下一步资产验收

1. 取得实际文件，确认原始格式、贴图、尺寸与材质。
2. 检查正背面、底部、空洞、支撑物及扫描缺陷，确定可开放的观察范围。
3. 在保留原件细节的前提下制作网页版本，记录处理过程与许可。
4. 测试加载、旋转、缩放、细节聚焦；成功后才能标记为“可进入游戏”。
5. 对已验收对象整理讲解依据和关联内容，再配置语音工具可操作的视角与热点。
