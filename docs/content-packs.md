# 唐宋本地联调内容包

`published/cn.song.core/0.1.4` 是宋代 36 项展品的本地联调包；`published/cn.tang.core/0.3.8` 是唐代 16 项展品的本地联调包。`assets` 下对应版本保存各自的资源索引和文件。故事及历史资料仍以包内的候选、来源和艺术演绎标记为准；这些包可供技术联调，不代表所有史实均已完成专家审核。

启动博物馆服务时，分别把 `MUSEUM_CONTENT_ROOT` 和 `MUSEUM_ASSET_ROOT` 指向仓库中的 `published` 和 `assets` 目录。切换前请确认不会覆盖其他现有内容包；前端默认使用上述版本，也可通过环境变量选择已安装的其他版本。

宋代此版本资源是图片，不含已入馆的 3D 模型；唐代此版本包含展示模型。来源和许可记录在对应的作者稿和 `assets/cn.tang.core/0.3.8/attribution.json`，文件通过内容索引中的 SHA-256 识别。本机语音设备和密钥由各自的本地配置管理，不在仓库中。
