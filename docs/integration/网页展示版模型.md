# 首批文物网页展示版模型

CW02d 从三件真实 `lod: source` GLB 量测面数、贴图和体积，再导出网页展示版。原件保留在 D 盘，不进 Git。展示版同样只写版本化资产根；作者稿只登记 `lod: display` 衍生清单。禁止把 `lod: source` 原件绑到 `presentation.display`。

测量与导出使用内容制作命令，不改器物几何拓扑以外的形制，不重画网格。减面只通过 meshoptimizer（gltf-transform 4.5.1 `simplify`），贴图只缩放与有损压缩颜色通道。法线/ORM 贴图不转 JPEG。

```powershell
uv run --project tools/content-pipeline content-pipeline record-source-profile `
  --model 'D:\7\History\models\e97f95d5781a4359b5a744b0cf0328fa\original.glb' `
```

清单不记录本机路径，只写哈希、字节、三角面、贴图 MIME/尺寸。重复测量覆盖同目录记录，不改源 GLB。

## 导出展示版

方法 JSON 声明逐步命令。允许的步骤：`weld`、`join`、`simplify`、`resize`、`jpeg`、`webp`、`prune`、`dedup`。`simplify.ratio` 必须在 `(0,1]`，避免把器物减成空壳。跨盘写出使用复制，避免 Windows `os.replace` 跨卷失败。

```powershell
uv run --project tools/content-pipeline content-pipeline export-display-glb `
  --source 'D:\7\History\models\774c1c5f1cd4484f98b68ee96d886950\original.glb' `
  --display 'D:\7\History\display\gilt-bronze-bull\display.glb' `
  --record 'D:\7\History\display\gilt-bronze-bull\display-profile.json' `
  --transform-cli 'D:\7\History\research\asset-tools\node_modules\@gltf-transform\cli\bin\cli.js' `
  --expected-version 4.5.1 `
  --method 'D:\7\History\display\gilt-bronze-bull\method.json' `
  --orientation 'D:\7\History\display\gilt-bronze-bull\orientation.json' `
  --note '保留原件；缩放4K贴图并压缩颜色通道。未达5—10MB不得宣称达标。' `
  --source-sha256 55904b44f74be7f87baa9a2b5c179ecfa26126be8e1f86b66b6c71a1e0865215
```

默认朝向与 CW02b 预览一致：造像碑正面朝 -Y；钱币铭文面朝 +X；卧牛四分之三、头朝左。加载后模型应与预览同物同朝向。成功记录含源/展示版哈希、三角面、贴图、耗时和 `meets_5_to_10mb_target`。该布尔值只反映字节是否 ≤10MB，不代替 H3 近景检查。
