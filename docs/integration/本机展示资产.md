# 本机展示资产受控访问

CW02c 把作者稿里的资产 ID 映射到本机真实 PNG/GLB，复制到版本化资源根后，由游戏服务按会话清单提供受控 URL。网页不得直接读 D 盘路径，MCP 也不传输 GLB。

源路径只写在被 Git 忽略的本机配置里，例如 `.local/asset-sources.json`：

```json
{
  "schema_version": 1,
  "sources": {
    "cn.tang.asset.votive-stele.preview": "D:/7/History/previews/votive-stele.png",
    "cn.tang.asset.kaiyuan-coin.preview": "D:/7/History/previews/kaiyuan-coin.png",
    "cn.tang.asset.gilt-bronze-bull.preview": "D:/7/History/previews/gilt-bronze-bull.png"
  }
}
```

暂存命令会核对内容包中的 `sha256`/`byte_size`，再复制到 `MUSEUM_ASSET_ROOT/<pack_id>/<version>/files/<sha256>.<format>`。重复版本不可覆盖。未声明的资产或哈希不一致会失败。当前三件源 GLB 仍是 `lod: source`，不要把它们当作网页展示模型暂存进生产清单。

```powershell
uv run --project tools/content-pipeline content-pipeline stage-assets `
  --pack content-src/packs/cn-tang `
  --sources .local/asset-sources.json `
  --out .local/assets
```

游戏服务读取 `MUSEUM_ASSET_ROOT`。网页通过已认证会话请求：

`GET /api/sessions/{session_id}/assets/{asset_id}`

响应使用清单中的 MIME、ETag=SHA-256 和私有缓存；Origin 必须在 `MUSEUM_ALLOWED_ORIGINS` 中。未知 ID、路径穿越、未引用资产和来源不匹配都会被拒绝。本卡不改展台 UI，也不优化模型。
