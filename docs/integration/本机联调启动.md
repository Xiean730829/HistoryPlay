# 三物本机联调包

CW02e 把当前唐朝作者稿 `cn.tang.core@0.2.0`（`publication_status: draft`）校验后，显式生成一份仅本机联调用的不可变副本。运行时版本写成新的 semver，并把 `publication_status` 改成 `published`，这样 `PublishedCatalog` 能装载，但**不覆盖作者 draft**，也不表示全馆历史审核或用户验收通过。

候选故事的审核状态写在副本里的 `rehearsal-notice.json`，开发提示仍把它们当作 candidate。H7 正式发布由 CW13e 另做。

## 本机资源来源

源路径只写在被 Git 忽略的 `.local/asset-sources.json`：

```json
{
  "schema_version": 1,
  "sources": {
    "cn.tang.asset.votive-stele.preview": "D:/7/History/previews/votive-stele.png",
    "cn.tang.asset.votive-stele.display": "D:/7/History/display/votive-stele/display.glb",
    "cn.tang.asset.kaiyuan-coin.preview": "D:/7/History/previews/kaiyuan-coin.png",
    "cn.tang.asset.kaiyuan-coin.display": "D:/7/History/display/kaiyuan-coin/display.glb",
    "cn.tang.asset.gilt-bronze-bull.preview": "D:/7/History/previews/gilt-bronze-bull.png",
    "cn.tang.asset.gilt-bronze-bull.display": "D:/7/History/display/gilt-bronze-bull/display.glb"
  }
}
```

联调包只暂存预览 PNG 与 `lod: display` GLB。源模型 `lod: source` 即使出现在来源映射中，也不会作为网页展示资产写入运行时清单。缺预览或展示版、哈希不一致、重复版本都会失败，并回滚已写出的内容目录。

## 生成命令

```powershell
uv run --project tools/content-pipeline content-pipeline rehearsal-pack `
  --pack content-src/packs/cn-tang `
  --sources .local/asset-sources.json `
  --content-root .local/published `
  --asset-root .local/assets `
  --version 0.2.1
```

成功后会得到：

- 内容：`.local/published/cn.tang.core/0.2.1/`
- 资源：`.local/assets/cn.tang.core/0.2.1/`
- 作者稿：`content-src/packs/cn-tang/manifest.yaml` 仍为 `0.2.0` / `draft`

单独暂存资源仍可用既有命令，版本目录跟作者稿版本走，不要拿它冒充联调 published 包：

```powershell
uv run --project tools/content-pipeline content-pipeline stage-assets `
  --pack content-src/packs/cn-tang `
  --sources .local/asset-sources.json `
  --out .local/assets
```

## 启动游戏服务

```powershell
$env:MUSEUM_CONTENT_ROOT = ".local/published"
$env:MUSEUM_ASSET_ROOT = ".local/assets"
$env:MUSEUM_ALLOWED_ORIGINS = "http://127.0.0.1:5173,http://localhost:5173"
uv run --project services/museum python -m museum.main
```

网页创建会话时必须指定运行时版本，不能把 draft `0.2.0` 交给 `PublishedCatalog`：

```http
POST /api/sessions
{"pack_id":"cn.tang.core","version":"0.2.1"}
```

随后读取 `GET /api/sessions/{session_id}/galleries/cn.tang.gallery.main` 与 `GET /api/sessions/{session_id}/assets/{asset_id}`。本卡不放宽正式目录读 draft，不部署、不向外发布。
