# 唐朝包本机联调

`build-rehearsal` 从作者 `draft` 包生成一个隔离、不可覆盖的本机联调目录。它不修改作者稿；输出内的运行时 `publication_status: published` 只为让 `PublishedCatalog` 加载该隔离副本，不代表历史审核或用户验收通过。生成的 `rehearsal-manifest.json` 保留来源状态，并将故事标记为 `candidate_unreviewed`。

## 准备本机资源映射

复制 `.env.example` 之外的示例到 Git 忽略目录 `.local/asset-sources.json`，为作者包中每个资产填写本机真实文件绝对路径。命令会核对全部资产的格式、大小和SHA-256；缺文件、哈希不符或包引用错误时，整个输出不会生成。当前唐朝源包含原始模型和预览资源；原始模型的暂存不代表已经达到网页展示版模型验收。

```json
{
  "schema_version": 1,
  "sources": {
    "cn.tang.asset.votive-stele.glb": "D:/History/assets/votive-stele.glb",
    "cn.tang.asset.votive-stele.preview": "D:/History/previews/votive-stele.png"
  }
}
```

确保这个映射为包内每个 `assets/*.yaml` 条目提供来源，然后运行：

```powershell
uv run --project tools/content-pipeline content-pipeline build-rehearsal `
  --pack content-src/packs/cn-tang `
  --sources .local/asset-sources.json `
  --out .local/tang-rehearsal `
  --version 0.2.1
```

输出目录包含独立的 `content/`、`assets/` 和 `rehearsal-manifest.json`。已存在的输出目录不能覆盖；修改作者稿或资源后使用新的输出目录和版本。

## 启动游戏服务与网页

在 PowerShell 的游戏服务终端设置本地内容与资源根，再启动服务：

```powershell
$env:MUSEUM_CONTENT_ROOT = ".local/tang-rehearsal/content"
$env:MUSEUM_ASSET_ROOT = ".local/tang-rehearsal/assets"
uv run --project services/museum python -m museum.main
```

另开PowerShell终端，设置同一运行版本后启动网页：

```powershell
$env:VITE_MUSEUM_PACK_ID = "cn.tang.core"
$env:VITE_MUSEUM_PACK_VERSION = "0.2.1"
npm run dev --workspace apps/museum-web
```

运行时再检查一次 `rehearsal-manifest.json` 的来源版本与故事候选状态。这个隔离目录只供本机工程联调，不要复制到正式内容根或据此签收H1—H8。
