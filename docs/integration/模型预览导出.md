# 唐朝文物真模型预览导出

CW02b 使用真实 GLB 离线渲染 PNG，不调用生图服务。渲染器、相机、环境、尺寸、署名以及模型/输出哈希均写入预览清单；清单不记录本机文件路径。当前没有可用的无头 Blender 时，按本文人工导出，再用同一个 `record-preview` 命令登记。人工导出必须来自所登记的真实 GLB，不能以生成图替代。

## 固定取景参数

为每件文物准备 UTF-8 JSON 取景文件。相机位置、目标和正交尺寸应按该件 GLB 的真实朝向校准；下面仅是格式示例，不代表三件模型都已完成画面验收。

```json
{
  "camera_location": [2, -3, 1],
  "target": [0, 0, 0],
  "orthographic_scale": 3.2,
  "resolution": [1024, 1024],
  "transparent_background": true,
  "environment": {
    "preset": "museum-neutral-v1",
    "color_management": "Standard"
  }
}
```

`museum-neutral-v1` 的固定灯光为主光 900W/5m、补光 450W/5m、轮廓光 700W/3m，世界底色为中性深灰；透明输出时世界强度为零。采用 Blender 离线渲染时，使用 Blender 4.2.0，脚本由 `render-preview` 配置上述参数。其他渲染器也必须记录精确名称与版本。

## Blender 图形界面人工导出

1. 使用 Blender **4.2.0** 打开真实 `.glb`，确认形制、朝向、材质与贴图正确；不要旋转模型来掩盖来源朝向差异。
2. 将取景文件中的 `camera_location`、`target`、`orthographic_scale` 和分辨率应用到相机；设置透明胶片与 RGBA PNG。按 `museum-neutral-v1` 设置三盏面光及中性世界环境。
3. 检查透明边缘没有底框或阴影方块，模型完整落在画面内，再渲染并导出 PNG。
4. 用下方命令登记。对三件文物分别执行一次，使用不同的预览资源 ID；同一清单会累积三条记录。文件名、模型路径与图片路径只作为本机命令参数，不会写入清单。

## 无头 Blender 渲染

在已安装 Blender 4.2.0 的机器上，准备以上格式的 `framing.json`，然后运行：

```powershell
uv run --project tools/content-pipeline content-pipeline render-preview `
  --renderer-path 'C:\Program Files\Blender Foundation\Blender 4.2\blender.exe' `
  --expected-version 4.2.0 `
  --asset-id 'cn.tang.asset.gilt-bronze-bull.glb' `
  --preview-asset-id 'cn.tang.asset.gilt-bronze-bull.preview' `
  --model 'D:\7\History\models\1985.74_recumbent_bull.glb' `
  --preview 'D:\7\History\previews\gilt-bronze-bull.png' `
  --manifest 'D:\7\History\previews\manifest.json' `
  --attribution '按模型来源记录填写授权与署名' `
  --framing 'D:\7\History\previews\gilt-bronze-bull.framing.json'
```

程序会先核对 Blender 版本，再对真实模型离线渲染；失败、版本不符或图片无效时不会登记成功记录。重复输入会复用现有记录。目标目录应在项目忽略的本机资产目录中，不要把模型或预览二进制提交到源码 Git。

## 人工导出登记

图形界面导出的 PNG 使用 `record-preview` 登记；该命令只校验真实 GLB 与 PNG、计算 SHA-256 并更新清单，不会渲染或伪造预览：

```powershell
uv run --project tools/content-pipeline content-pipeline record-preview `
  --asset-id 'cn.tang.asset.gilt-bronze-bull.glb' `
  --preview-asset-id 'cn.tang.asset.gilt-bronze-bull.preview' `
  --model 'D:\7\History\models\1985.74_recumbent_bull.glb' `
  --preview 'D:\7\History\previews\gilt-bronze-bull.png' `
  --manifest 'D:\7\History\previews\manifest.json' `
  --renderer Blender `
  --renderer-version 4.2.0 `
  --attribution '按模型来源记录填写授权与署名' `
  --framing 'D:\7\History\previews\gilt-bronze-bull.framing.json'
```

成功登记只说明资产格式、哈希与取景元数据已记录，不代表策展人已通过“三件真物同物同朝向、透明边缘无底框”的 H1 画面验收。当前工作区没有 Blender 可执行文件，也没有三件首批模型的已验收预览，因此不在仓库伪造图片、资源 URL 或验收结论。

## 批量登记

三件图片准备好后，可改用一份批量输入清单。`model_path` 与 `preview_path` 支持相对批量文件的路径；其他字段与单项命令一致。程序先验证整批，再一次性更新输出清单，任一条目无效时不会留下部分成功记录：

```json
{
  "schema_version": 1,
  "previews": [
    {
      "asset_id": "cn.tang.asset.gilt-bronze-bull.glb",
      "preview_asset_id": "cn.tang.asset.gilt-bronze-bull.preview",
      "model_path": "../models/1985.74_recumbent_bull.glb",
      "preview_path": "gilt-bronze-bull.png",
      "renderer": "Blender",
      "renderer_version": "4.2.0",
      "attribution": "按模型来源记录填写授权与署名",
      "framing": {
        "camera_location": [2, -3, 1],
        "target": [0, 0, 0],
        "orthographic_scale": 3.2,
        "resolution": [1024, 1024],
        "transparent_background": true,
        "environment": {
          "preset": "museum-neutral-v1",
          "color_management": "Standard"
        }
      }
    }
  ]
}
```

将卧牛、钱币与造像碑分别写成独立条目，再运行：

```powershell
uv run --project tools/content-pipeline content-pipeline batch-record-preview `
  --batch 'D:\7\History\previews\batch.json' `
  --manifest 'D:\7\History\previews\manifest.json'
```

清单字段保存模型与PNG的SHA-256，不保存这两个路径。批量登记只保证整批格式校验和写入；真实画面是否同物同朝向、透明边缘是否无底框，仍需人工查看后再报H1验收。
