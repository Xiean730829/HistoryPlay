## 共享几何契约

`scene3d/layout.ts`是建筑、GLB、拾取体与镜头的坐标来源。世界X左右、Y向上、负Z向历史深处。

| 字段 | 定义 |
| --- | --- |
| x/z | 当前展柜的世界坐标中心 |
| stepIndex | 当前侧柜所对应中央阶梯级数 |
| walkY | 该级中央步道顶面世界高度 |
| landingY | 侧柜平台顶面世界高度，首版等于walkY |
| plinthTop/top | 柜内真实承托面世界高度，top为兼容别名 |

踏步高0.16米、深0.48米、中央宽4.2米；`stairStepPlacement(n)`返回该级中心z与顶面walkY，不能将中心z当踏步前沿。三物级数4/14/24，脚下平台0.64/2.24/3.84米，承托面1.72/3.32/4.92米。模型最低点为承托面加0.012米，倾转过程中也维持接触。

`stairCamera.ts`把世界行进镜头与文物观察姿态分开。初始中央低处看向上行阶梯，后续镜头按脚下阶梯高度加1.75米眼高；物件正面朝中央参观者。故事层不卸载场景，返回仍由服务器原站和相机姿态决定。

## 点击和呈现约束

- 点击已聚焦文物只切本地近看镜头；不发会被拒绝的重复locate，也不伪造committed。
- 点击其他文物走既有HTTP命令、版本和票据；当前焦点来自服务器，不能用另一套本地游戏状态代替。
- 真实三维拾取体覆盖钱孔/底座，玻璃与透明标签可穿透；实体柱墙遮挡后排。玻璃可设 `userData.pickThrough=true`，不要标成artifactId；拾取体由World管理。
- 相机、物体朝向和真实可见帧达到当前版本后才发呈现回执；拖动预览、命令提交、降级状态不能冒充rendered。

## 夜间继续的优先顺序

1. 同一坐标契约接齐最终阶梯建筑与视觉主题，整体构建切换5188，完成真实玩家H1/H2复验。
2. 读取已绑定背景asset_ids的多节点故事；故事画面/字幕/正文同一版本。全量唐朝未审核素材与缺模型项诚实区分，不能把运行目录存在当历史审核完成。
3. 一段真实播放结束才合法推进下一节点；插话立刻停止自动连播并保留同段，返回后旧回调不得继续推进。
4. 新页面语音Origin须显式受控配置并测试；用户先断开原设备页面，不能因服务器配置可读就宣称真实声音通过。

浏览器接口当前不可用，尚未取得新阶梯的截图、硬件帧率、用户点击和声学验收证据；工程测试与最终体验验收分别记录。
