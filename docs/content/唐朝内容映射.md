# 唐朝作者稿与运行 Schema 映射

## CW13a 候选导入

`content-src/imports/tang-r02/id-map.yaml` 将作者卡代码映射到稳定文物ID、内容包和显式分类。A04 造像碑、A07 开元通宝、R02 鎏金卧牛沿用已存在的稳定ID。C01 伊拉克蓝碗保留 `iq.abbasid` 命名空间，单独进入阿拔斯比较候选包。

作者源数据留在本机作者目录，不提交D盘路径、图片或原始导出JSON。使用内容管线生成独立候选包：

```powershell
$authorContent = $env:HISTORY_AUTHOR_CONTENT
if (-not $authorContent) { throw '请在本机设置 HISTORY_AUTHOR_CONTENT，不要把本机目录写入版本库' }
uv run --all-packages python -m content_pipeline.cli import-tang-cards-candidate `
  --source-root $authorContent `
  --candidate-root content-src/candidates/tang-r02 `
  --id-map content-src/imports/tang-r02/id-map.yaml
```

该命令读取20张卡、10章/40节点时间线、人物、历史人物、来源、事实卡和场景绑定；输出只位于 `content-src/candidates/tang-r02/`，不是作者运行包。`cn-tang` 与 `iq-abbasid` 两个包各自通过当前公共 Schema 校验。候选清单保持 `draft`，未导入图片或模型资产，不会被运行时包发现。

时间线、创作人物与历史人物的稳定ID、章节节点ID以及卡片/章节场景绑定记录在 `authoring-index.json`，正文主线留给CW13c逐章导入。卡片支线转成现有 `story`/`story-node` Schema：事实等级F/R/C/U原样保留，创作对白保留C，结束节点按现有返回展厅节点约定生成；章节场景图片只登记为待审核引用，不绑定到运行节点。

作者卡精度标签 `catalog_range` 映射为Schema `range`，`century_with_qualifier` 映射为 `century`；原始日期措辞保留在 `display_label`，精度转换说明写入 `calendar_note`。缺整数年代边界的卡片不会推造年份。当前A08年代冲突、A09“870年之前”、R08“约735年”与缺馆藏号的A12列入待补清单；因此16件进入Schema候选，4件保留为未导入记录。

重复运行使用 `.import-state.json` 比对上次生成哈希；如果候选文件被手工修改，本次导入会停止并列出冲突路径，不覆盖手工内容。只有候选内容审核、资源归属/许可核查与完整章节导入完成后，才可另行提出进入作者包或发布包的PR。

可复核候选包：

```powershell
uv run --all-packages python -m content_pipeline.cli validate --pack content-src/candidates/tang-r02/cn-tang
uv run --all-packages python -m content_pipeline.cli validate --pack content-src/candidates/tang-r02/iq-abbasid
```
