# ADR 0001：语音控制路由

- 状态：待真实能力预检
- 日期：2026-10-24

## 背景

长廊语音动作需要关联当前玩家输入轮次。停止播放或发送一个本地 `abort` 消息，不能单独证明服务端不会继续返回旧工具结果。旧版网
页桥接代码可用于理解本地转发行为，但静态代码不能证明当前账号、设备或上游服务的能力。

## 选项

1. 小智直连MCP工具，并使用官方可验证的轮次/取消关联。
2. 保留小智MCP入口，由可信本地编排关联输入轮次并调用游戏控制接口。

## 当前决定

暂不选路。先完成CW09p真实预检并记录工具发现、指定稿播放、打断竞态和来源关联证据。若直连不能满足旧任务隔离，优先采用选项2；不以
点击确认替代语音控制，也不通过伪造 `hello.features` 宣称已接通。

## 后果与验收

- 本轮静态预检只用于汇总旧桥可见行为，不能关闭CW09p或H5。
- 不将账号凭据、设备令牌、MCP令牌、原始录音或完整私人对话保存到仓库。
- 真实预检完成后更新本ADR的状态、选路和脱敏证据；无法证明的能力保持未验证。
