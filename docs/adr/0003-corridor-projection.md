# ADR 0003：长廊投影遵循展厅顺序

- 状态：已采纳
- 日期：2026-10-24
- 任务：CW05a

## 决策

网页只接收服务端投影好的可见文物序列，并原样保留其顺序。该序列的语义为“近到远”：当前焦点居中；序列中焦点之后的展位逐步变小、变暗并退入纵深；焦点之前的展位已在来访者身后，裁出视口。超过四个深度步长的远处展位也不绘制，但仍保留其服务端序号，不重新编号。

窄屏可以收紧横向间距，不能改变展位顺序、焦点或可见性窗口。年代区间用于标注，不换算成空间距离。客户端不能根据窗口尺寸自行重排服务端的 `display_order`。

## 后果

- 视觉投影是纯函数，可在渲染器之外验证边界和窗口语义。
- 服务端序列决定展台身份和顺序；布局仅生成相对深度、缩放、横向位置、层级与亮度。
- 以后若需要把被裁掉的远站纳入窗口，应调整共享的窗口策略并验证宽窄屏一致性，而不是通过年份或客户端排序改变路线。
